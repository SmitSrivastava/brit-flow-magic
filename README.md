# BritGPT Flywheel

Create similar flywheel from the attahced pdf. Take details from the the other attached pdf. Create main circular flywheel BritGPT flywheel, and other flywheels input to this flywheel and also get input from the BritGPT. On the opening page show the summary flywheel like the attached pdf image. when we click on each box it opens two pop ups - shows input to that box and output form that box. Use Britannia color theme. Add animation showing circular arrow movements - arrows coming out of the box and going to the box where this is inpu.
